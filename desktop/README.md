# Diart — Web-App (PWA)

Vue 3 + Vite + TypeScript. PDF-Text wird mit MuPDF.js (WASM) gelesen, Positionen in `src/extractor/` extrahiert, Excel in `src/export/` erzeugt.

## Entwicklung

```bash
npm install
npm run dev
```

## Build & Preview

```bash
npm run build
npm run preview
```

## Tests

```bash
npm run test:run
```
